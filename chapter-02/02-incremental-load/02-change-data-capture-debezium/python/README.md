# Change Data Capture - Debezium

All the components (dataset generator, PostgreSQL, Apache Kafka, Kafka Connect with Debezium, Apache Spark job) run in
Docker containers defined in [docker/docker-compose.yaml](docker/docker-compose.yaml); you don't need a local Python
environment or JDK. The commands below require Docker Compose v2.

1. Generate the dataset and start the containers:
```
cd docker/
docker-compose --profile stream-processor down --volumes; docker-compose up
```
2. Register the Kafka Connect consumer that will stream PostgreSQL records to Apache Kafka, in a new terminal opened in
this demo's directory. The first command waits until Kafka Connect is ready to accept connectors:
```
cd docker/
until docker exec cdc_kafka_connect curl -sf http://localhost:8083/connectors > /dev/null 2>&1; do echo "Waiting for Kafka Connect..."; sleep 3; done
docker exec -i cdc_kafka_connect curl -sSi --fail-with-body -X POST -H "Accept:application/json" -H  "Content-Type:application/json" http://localhost:8083/connectors/ -d @- < register-postgresql-connector.json
```
3. Open the [visits_stream_processor.py](visits_stream_processor.py)
* it's a classical Structured Streaming consumer to process created (`filter('visit.payload.op = "c"')`) records
  and aggregate them to 30-seconds windows
4. Run the `visits_stream_processor.py` in a new terminal opened in this demo's directory; you should see the windows printed in the console:
```
cd docker/
docker-compose up --build visits_stream_processor
```
The first run builds the image (it downloads PySpark and the Apache Kafka connector jars) and can take a few minutes.
5. Run Apache Kafka consumer to see the records generated by the Kafka Connect:
```
docker exec -ti docker_kafka_1 kafka-console-consumer.sh \
    --bootstrap-server kafka:9092 \
    --from-beginning \
    --property print.key=true \
    --topic dedp.dedp_schema.visits
```

## Cleanup
```
cd docker/
docker-compose --profile stream-processor down --volumes
```
